# 📝 Real-Time Collaborative Notes App

A production-ready real-time collaborative notes application built with ASP.NET Core SignalR and Blazor. Multiple users can edit the same document simultaneously with instant synchronization.

## ✨ Features

- **Real-time collaboration** - Multiple users can edit the same note simultaneously
- **Instant synchronization** - Changes appear in all connected browsers instantly
- **User presence indicators** - See who else is viewing the note
- **Typing indicators** - Know when others are typing in real-time
- **Custom usernames** - Users can set and save their names
- **Persistent storage** - Notes are saved to SQLite database

## 🛠️ Technology Stack

- ASP.NET Core 8.0
- SignalR WebSockets
- Blazor Server
- Entity Framework Core
- SQLite
